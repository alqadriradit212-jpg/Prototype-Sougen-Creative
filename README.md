# Sougen Creative Management — Prototype Website

Prototype website Sougen Creative Management (EO festival budaya Jepang & bazar UMKM) untuk Praktikum Desain dan Pemrograman Web.
Satu file `index.html` tanpa framework dan tanpa backend, semua data bersifat contoh.

## Fitur
- **Halaman tamu**: Beranda (event gratis, Gallery), Tentang, Gallery, Sponsor, Masuk/Daftar.
- **Halaman user** (setelah login): event berbayar, detail event dan pembelian tiket, Sewa Booth tenant, pembayaran simulasi (QRIS, Transfer VA, E-wallet), E-Ticket ber-QR.
- **Halaman admin**: Scan QR Gate (validasi check-in dan anti-duplikat), Rekap Tiket dan Data tenant (unduh CSV).
